# Zaberi RF (PHP)

Цифровой сервис для жителей Новосибирска:
- регистрация и вход;
- личный кабинет пользователя с добавлением продукта, адресом и фото;
- главная страница с полноэкранной картой;
- фильтры по категориям и подкатегориям;
- админ-панель для управления пользователями и удалением товаров/точек.

## Запуск

1. Установите PHP 8.1+ (в системе должна работать команда `php`).
2. Создайте базу данных из схемы:

```bash
php init_db.php
```

3. Из корня проекта выполните:

```bash
php -S localhost:8000
```

4. Откройте:

`http://localhost:8000/public/index.php`

База данных SQLite создается автоматически в `data/app.sqlite`.

## Администратор

- Логин: `admin@zaberi.rf`
- Пароль: `admin123`

Администратор может:
- удалять пользователей;
- удалять товары (и соответствующие точки на карте);
- просматривать все товары и пользователей в `public/admin.php`.
